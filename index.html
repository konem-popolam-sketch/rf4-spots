Точки клёва с фильтром по карте, уровню и навыкам

Данные собраны из публичных постов игроков на rf4-map.ru и rf4intel.com. У каждой точки — видимая ссылка на источник.

  • —точек с высокой уверенностью
  • —дата актуальности

Не удалось загрузить данные

Страница открыта по file://, а браузер запрещает странице читать JSON-файлы с диска. Поэтому те же данные лежат рядом во встроенном снимке site/data/rf4-data.js и site/data/rf4-spots.js — они пересобираются из data/*.json командой node site/build-data.mjs.

Запасной путь: выберите файлы data/dataset.json, data/waterbodies.json, data/skills.json, data/spots.json вручную.

Поиск по части названия: «щук» найдёт щуку, «окун» — окуня. Пустое поле — все виды.

Навыки

Отметьте навыки, которые уже открыты у вас. Пока не отмечен ни один навык, фильтр выключен и показывает все точки. Уровни открытия навыков не публикует ни один разрешённый источник, поэтому рядом с каждым навыком стоит «не проверено».

Дополнительно

Квадрат — префиксом (например, A — весь ряд), координата — как 21:179.

Оценка считается по числу подтверждённых параметров точки (способ, квадрат, клипса, глубина, наживка, дата поста).

Крафтовые навыки

Не влияют на доступность точки — уровни тоже не проверены.

      Актуальность

      Дата актуальности данных: —. У каждой точки своя дата проверки — checked_at.

      Точки — это публичные посты игроков. Они не проверены разработчиком и могут устареть: погода, время суток и патчи меняют клёв.

      Источники

        Используются только текстовые факты и ссылки. Картинки с сайтов источников не берутся, API не используется.
