# Точки клёва Russian Fishing 4

Статический справочник: фильтр по водоёму, уровню игрока (1–34), навыкам и рыбе.
Без сборщика, сервера, npm и внешних доменов — открывается двойным щелчком по `index.html`.

**Данные:** 984 точки, 18 водоёмов, 11 навыков, 196 видов рыб. Дата актуальности — в `data/dataset.json`.

## Источники и права

Данные собраны из публичных постов [rf4-map.ru](https://rf4-map.ru) и [rf4intel.com](https://rf4intel.com).
Права остаются у авторов постов и источников; у каждой точки в интерфейсе есть ссылка на источник.
Проект неофициальный и не связан с разработчиком игры.

## Как обновить данные

```sh
node site/build-data.mjs      # пересобрать встроенный снимок site/data/*.js из data/*.json
node tools/check-site.mjs     # 85 проверок страницы
node tools/build-publish.mjs  # пересобрать этот репозиторий в publish/rf4-site/
```

Затем скопировать содержимое `publish/rf4-site/` сюда и закоммитить.

## Ограничения

- Картинки карт не публикуются: `map_image` всегда `null` (запрещено лицензией источника).
- Уровни открытия навыков источник не сообщает — везде «не проверено».
- 727 точек без определённого навыка видны и помечены; скрыть их можно только явной галочкой.
- Пустые поля показаны как «Источник не сообщает: …», а не как `0`.
